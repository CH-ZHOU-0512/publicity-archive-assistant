# 快速开始

## 系统要求

- 64 位 Windows 10 或 Windows 11；
- 系统可正常使用 Microsoft Edge；
- 采集网页时能访问目标新闻网站。

目标电脑不需要安装 Node.js、Chrome、Python 或数据库。

## 安装

1. 打开 [最新 Release](https://github.com/CH-ZHOU-0512/publicity-archive-assistant/releases/latest)。
2. 下载 `宣传记录助手-安装程序-1.0.0.exe` 和 `SHA256.txt`。
3. 在 PowerShell 中校验文件：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\宣传记录助手-安装程序-1.0.0.exe'
```

4. 确认结果与 `SHA256.txt` 一致后运行安装程序。
5. 如果 SmartScreen 提示“Windows 已保护你的电脑”，核对哈希后选择“更多信息 > 仍要运行”。

## 第一次生成 PDF

1. 双击桌面的“宣传记录助手”。
2. 程序会在默认浏览器中打开本地页面。
3. 点击“选择文件夹”，设置 PDF 输出目录；也可以沿用默认的“文档\宣传记录PDF”。
4. 在输入框粘贴网址，每行一条。
5. 保持“自动判断”，点击“开始处理”。
6. 若标题或发布日期无法可靠识别，请核对后确认。
7. 状态变为“已完成”后，点击“查看 PDF”。

历史记录默认显示最近 3 条；点击“展开全部”查看完整记录，再点击“收起”恢复简洁页面。

## 什么时候使用浏览器扩展

出现以下情况时使用扩展兜底：

- 微信公众号要求验证；
- 文章只有登录后可见；
- 站点限制自动化浏览器，但在日常浏览器中能正常显示。

在应用里点击“打开离线扩展目录”，然后到 Edge 的 `edge://extensions` 开启开发人员模式，选择“加载解压缩的扩展”。确认文章已经完整显示后，从扩展弹窗提交采集。

## 正确退出

在页面右上角点击“退出程序”。只关闭浏览器标签页不会停止后台程序；再次双击快捷方式会重新打开页面。
