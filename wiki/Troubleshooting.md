# 故障排查

## 页面没有自动打开

再次双击桌面快捷方式。如果仍未打开，可在浏览器访问 `http://127.0.0.1:43117`。若无法访问，先在任务管理器结束残留的“宣传记录助手”，再重新启动。

## 提示找不到 Microsoft Edge

确认 Windows 自带 Edge 没有被卸载，并完成系统更新。程序不要求把 Edge 设为默认浏览器。

## 网页要求验证或只显示登录提示

先在 Edge/Chrome 中手动打开目标文章，完成站点要求的验证并确认正文完整显示，再使用应用提供的离线扩展采集。

## PDF 正文左右被裁掉

1. 确认使用 1.0.0 正式 Release 或更高版本；该版本已修复固定宽度、`min-width`、负边距与横向溢出导致的桌面网页裁切。
2. 点击任务“重试”，让新版本重新生成。
3. 若仍能复现，请在 Issue 中提供公开网址、Windows 版本和脱敏截图。

## PDF 在页首或页尾切到文字

新版本会避开文字行切页，但极端绝对定位、Canvas 字体或站点自绘文本可能无法提供文字边界。请提交公开样本；若浏览器中内容依赖登录态，可尝试扩展链路。

## 标题或日期需要确认

这是保护归档准确性的设计。请按原文核对后确认；程序不会用采集日期代替无法识别的发布日期。

## PDF 图片不完整

先确认浏览器里滚动到页面底部后所有图片都能正常加载。重试一次；如果站点限制自动化浏览器，改用扩展采集。

## SmartScreen 阻止安装

当前安装包没有商业代码签名。请只从官方 Release 下载，先用 `Get-FileHash` 核对 SHA-256，再选择“更多信息 > 仍要运行”。

## 卸载后文件还在

这是预期行为。卸载只移除程序和快捷方式，默认保留 PDF、任务历史与设置，防止误删归档。如果确定不再需要，请手动处理这些个人数据。
