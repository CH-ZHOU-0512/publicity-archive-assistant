不只是“网页打印”

保留原貌，也保留来路

阅读模式会丢掉媒体身份，整页截图会让文字小到无法阅读。宣传记录助手在视觉保真、打印可读和来源追溯之间做了专门设计。

01

桌面新闻页不再被视口裁掉

固定 1440/1600px 布局、min-width、负边距、横向溢出和宽图，都按正文实际可见边界纳入截图，并在左右保留安全余量。

正文左侧正文右侧
02

文字感知的 A4 分页

按可打印区域换算切片高度，尽量把切线放在文字行之间；长图自然跨页，短尾页只做克制缩放。

03

每页都有追溯线索

来源域名、采集时间、页码和原文二维码写入页脚，文件名采用原文标题与发布日期。

04

失败不会拖垮整批任务

任务持久化到 SQLite，支持批量、确认、重试与重启恢复。历史默认显示 3 条，可随时展开或收起。

技术难点

真正困难的，是网页一直在变

新闻站点并不是静态文档。页面尺寸、懒加载、登录态、反爬、字体和元数据都可能让一次看似简单的“另存为 PDF”失真。

01

页面稳定性

滚动触发懒加载，等待字体和图片解码，监测高度连续稳定，不把加载遮罩存进档案。

02

双采集路径

公开网页走隔离 Edge；验证或登录态页面由离线扩展采集用户已看到的内容，不导出 Cookie。

03

可靠元数据

综合 JSON-LD、Open Graph、站点适配器与页面语义；无法确认时交给用户，不用采集日期冒充原文日期。

04

不可信网页的安全边界

本机监听、会话校验、协议限制、SSRF 防护与跳转复检共同约束渲染器。

本地优先

你的档案，不经过我们的服务器

项目没有自建云端服务。网址、任务历史、设置、截图和 PDF 都在当前电脑处理；本地 API 只监听 127.0.0.1。

  • 每次渲染使用隔离的临时 Edge 用户目录
  • 阻止回环、私网、链路本地与云元数据地址
  • 扩展不保存密码、Cookie 或文章内容副本
