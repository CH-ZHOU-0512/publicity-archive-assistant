# 已确认决策与真实样本

确认日期：2026-08-15。

## 产品与分发

- 兼容目标：Windows 10 64 位和 Windows 11 64 位；
- 分发方式：标准安装程序；
- 运行方式：应用仅在本机运行，浏览器访问 `127.0.0.1`；
- 数据保存：保留本地任务历史，不额外复制 PDF；
- 多电脑策略：每台电脑完全独立，不同步配置和历史；
- 浏览器扩展：允许安装，仅在普通本地渲染失败时使用；
- 用户界面浏览器：不要求 Chrome，打开系统默认浏览器，兼容 Edge 和主流国产 Chromium 浏览器；
- 网络条件：学校电脑不能访问境外网络，安装和运行均不得依赖 Google、浏览器商店或在线下载浏览器；
- 页脚：简洁存证页脚，包含媒体来源、原文链接、二维码、采集时间和页码；
- 原貌原则：裁取网页真实品牌与文章区域，不由应用重新设计媒体版式；
- 导航与侧栏：原网页正常可见且样式完整时允许保留；样式失效后出现的大段裸链不得输出；
- 批量输入：首期支持多行粘贴，不要求 CSV/XLSX 导入；
- 页面边距：默认 8 mm，提供 5 mm 紧凑模式。

## Windows 兼容策略

渲染内核采用 Puppeteer Core，后台调用 Windows 现有的 Microsoft Edge。程序不要求安装 Chrome，不访问 Google，不在安装或运行时下载浏览器。浏览器扩展随安装包离线提供。

安装包发布前必须在干净的 Windows 10 64 位和 Windows 11 64 位环境分别完成：启动、网页加载、结构化 PDF、截图 PDF、中文字体、批量任务和卸载测试。
