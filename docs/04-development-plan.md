# 开发计划

## 阶段 0：技术验证

目标：用真实样本验证最关键的不确定性，不制作完整界面。

- 建立本地新闻网页夹具；
- 选择 5 个代表性真实网址；
- 验证标题、日期和媒体品牌提取；
- 验证 Puppeteer Core/Edge 懒加载与截图分块；
- 验证正文区域裁切、A4 铺满策略以及 300 DPI 截图清晰度；
- 为一个普通新闻站和一个微信公众号文章生成实验 PDF；
- 把实验 PDF 按实际大小打印，检查文字、图注和图片细节；
- 记录微信访问限制和动画表现；
- 确认目标 Windows 10/11 电脑的 Edge 可被本地应用离线调用；
- 验证本地启动器、Local API 和渲染子进程的最小闭环。

完成条件：普通新闻和微信样本各有至少一份可接受 PDF，并明确剩余风险。

## 阶段 1：核心生成与批量任务

- 单网址和多行网址导入；
- 导入预览、网址去重和安全校验；
- 本地批次队列、状态恢复和进度页面；
- 失败项重试、批次结果汇总和打开输出目录；
- 通用标题、日期、媒体提取；
- 结构化高保真引擎；
- A4 铺满策略和清晰度自动检查；
- 预览、人工修正和自动命名；
- 原文二维码和采集信息；
- 下载及临时文件清理；
- 单元测试与本地集成夹具。

完成条件：普通新闻网站和学校官网样本通过验收，混合批次不会因单条失败而中断。

## 阶段 2：微信与动态页面

- 截图存证引擎；
- 自动滚动、页面稳定和图片完整性检测；
- GIF、Canvas、滚动动画和视频封面处理；
- 微信验证页和空白页识别；
- 分块截图分页及视觉回归测试。

完成条件：公开可访问的微信样本通过验收，失败场景有明确提示。

## 阶段 3：本地打包与内部试用

- 渲染子进程隔离和资源限制；
- 把 Web 界面、Local API 和运行时制作成本地安装程序，不在安装或运行时下载浏览器；
- 启动后自动打开浏览器，退出后正确停止本地进程；
- 应用仅监听 `127.0.0.1`，不对局域网开放；
- 设置本地日志、健康检查和临时文件清理；
- 验证便携包或安装包在干净的目标 Windows 电脑上可用；
- 真实打印测试；
- 由学院使用者完成 5 份材料试用；
- 根据试用结果完善站点规则。

完成条件：内部用户无需开发人员介入即可完成一次生成和下载。

## 阶段 4：可靠性增强

- 浏览器扩展，处理需要用户浏览器环境的页面（已提前纳入首期离线备用）；
- 上传长截图转 PDF；
- 长期归档、搜索和权限；
- 站点规则管理与运行指标。

## 已确认的开工条件

以下信息不会阻止技术验证，但会影响本地分发方式：

已在 `docs/05-confirmed-decisions.md` 中确认 Windows 10/11、标准安装程序、本地历史、电脑独立运行、备用扩展、简洁存证页脚、多行粘贴、页面边距和首批真实样本。

## 第一轮开发任务建议

首个开发任务是“本地真实网页渲染技术验证”。验证结果将决定微信能否由本机 Puppeteer Core/Edge 稳定完成，以及浏览器扩展是否需要提前到首期。
