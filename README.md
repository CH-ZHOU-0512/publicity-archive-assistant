# 宣传记录助手

面向学院宣传材料归档的本地“网址转 PDF”工具。它的重点不是把网页变成阅读模式，而是完整、可信地保留媒体品牌、文章内容与原始出处。

应用只在用户电脑上运行：启动本地程序后由浏览器访问 `localhost`，网页处理、PDF 生成和记录保存均在本机完成，不部署线上服务器，不向第三方上传文章内容。

## 已确定的产品原则

1. 用户粘贴网址后，应能预览并一键生成 PDF。
2. 媒体 Logo、网站名称、标题、日期、作者、来源、正文和原图属于应保留内容。
3. 广告、弹窗、登录引导、推荐阅读等属于默认清理内容。
4. 普通新闻网页、学校官网和微信公众号默认按浏览器实际显示效果输出高保真截图 PDF。
5. 结构化、文字可搜索 PDF 仅作为手动备用，不以牺牲原网页版式换取“干净排版”。
6. PDF 默认命名为 `原标题_YYYY-MM-DD.pdf`，标题与日期允许在生成前修正。
7. PDF 中附原文 URL、二维码与采集时间，保证材料可追溯。
8. 首期支持每行粘贴一条网址进行批量处理，失败任务不影响其余任务。
9. PDF 内容铺满 A4 可打印区域；文字和图片不得因整页缩小或过度压缩而模糊。

## 本地开发

```powershell
npm install
npm run dev
```

生产构建与 Windows x64 离线安装包：

```powershell
npm run build
npm run pack:win
```

安装后的任务历史保存在当前 Windows 用户的应用数据目录，PDF 默认保存在“文档\\宣传记录PDF”，卸载程序默认不删除历史和 PDF。

安装包自带应用运行环境、SQLite、Web 界面和 PDF 处理依赖。目标电脑不需要预装 Node.js、Chrome、数据库或开发工具，也不在安装和运行时联网下载组件；网页渲染使用 Windows 10/11 自带的 Microsoft Edge。

遇到反爬、登录态或微信公众号验证页面时，可在应用中打开“离线扩展目录”，按目录内说明把随安装包提供的 Manifest V3 扩展加载到 Edge 或其他 Chromium 内核浏览器。扩展将当前浏览器实际显示的文章分段截图并交回本地程序，仍保存在统一输出目录和任务历史中。
